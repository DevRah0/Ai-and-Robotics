# GeoLab Personal / مختبر المواقع الشخصي

**الإصدار 0.2.0 | SwiftUI + MapKit + CoreLocation | iOS 17+**

مشروع iPhone شخصي مفتوح المصدر مستوحى من مبادئ واجهة المستخدم في الصور المرجعية التي قدمها المستخدم، بدون استخدام شيفرة التطبيق المغلق أو شعاراته. لا توجد خوادم أو حسابات أو اشتراكات.

## ما الذي يعمل؟ / Features

- **خرائط Apple / Apple Maps:** أنماط قياسي، مختلط، أقمار صناعية، عرض ثلاثي الأبعاد، تحديد النقاط باللمس، البحث عبر `MKLocalSearch`.
- **المفضلة / Favorites:** إضافة، حذف، تصنيفات، قائمة معالم، سجل مواقع تم تحديدها.
- **محاكاة محلية / In-app preview:** معاينة موقع على الخريطة، عصا حركة يدوية، أوضاع ثابت/مشي/دراجة/سيارة/طيران.
- **المسارات / Routes:** بناء المسار بإضافة نقاط من الخريطة، حفظ المسارات وإدارتها، استيراد وتصدير GPX، تشغيل تقدمي داخل التطبيق من نقطة لأخرى.
- **الفحص / Diagnostics:** بيانات CoreLocation الحالية، علم `isSimulatedBySoftware` عند توفره، علم الملحق الخارجي، الدقة الفعلية، عمر القراءة، واختبار سياج جغرافي تجريبي.
- **النتائج / Reports:** حفظ محلي لسجل الاختبارات وتصدير JSON.
- **الخصوصية / Privacy:** تخزين محلي باستخدام UserDefaults؛ لا توجد صلاحية VPN أو اتصال بنظام حضور حقيقي.

> **تنبيه:** جميع عمليات المحاكاة في هذا المشروع داخل التطبيق فقط. لا يغير التطبيق إحداثيات GPS التي تستقبلها التطبيقات الأخرى، ولا يتضمن وظائف إخفاء التلاعب أو تجاوز إثبات الحضور.

## البناء في GitHub Actions

يوجد Workflow جاهز في `.github/workflows/ios-build.yml` يبدأ عند التغيير أو من صفحة Actions. يعمل على `macos-15` ويشغّل اختبارات سلامة المشروع، ثم يبني:

- `GeoLab-Simulator.zip`: تطبيق iOS Simulator للتجريب عبر محاكي Xcode.
- `GeoLab-UNSIGNED.ipa`: حزمة **غير موقعة وغير قابلة للتثبيت مباشرة على iPhone**؛ تُستخدم لفحص صحة البناء فقط.

للتثبيت على جهازك، اقرأ [دليل التوقيع](docs/SIGNING.md). تحتاج إلى حساب Apple وتوقيع متوافق مع معرّف التطبيق وجهازك. لا ترسل الشهادات أو بيانات الحساب في المحادثة ولا تضعها في المستودع.

## البناء من Mac

```sh
xcodebuild -project GeoLab.xcodeproj -scheme GeoLab \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

## التشغيل

1. افتح `GeoLab.xcodeproj` في Xcode على Mac.
2. عيّن فريق التوقيع ومعرّف تطبيق فريد عند البناء لجهاز حقيقي.
3. امنح إذن الموقع أثناء الاستخدام.
4. اختر هدفًا على الخريطة؛ المعاينة لا تغير GPS الحقيقي.
5. في صفحة المسارات، أضف نقطتين على الأقل أو استورد `Examples/Makkah_Test.gpx`.
6. شغّل المسار أو استخدم عصا الحركة، ثم اختبر السياج الجغرافي المحلي من صفحة الفحص.

## قيود حاليّة

لم يتم تجميع المشروع على macOS من بيئة هذه المحادثة. فحوص Swift syntax وملف مشروع Xcode واختبارات Python البنيوية ناجحة، ويظل **البناء الحقيقي على GitHub Actions مطلوبًا** للتأكد من سلامة الربط والتوافق.

اطلع على [مصفوفة الميزات](docs/FEATURE_MATRIX.md) لمعرفة الفرق التفصيلي بين المشروع والخصائص المستنتجة من التطبيق المرجعي.
